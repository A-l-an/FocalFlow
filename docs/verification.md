## Scope of the source delta

Android production code/resources/build inputs are byte-identical to the selected
baseline. Python model/provider payload logic, prompts, preset data, protocol and
business-stage functions are unchanged. `run.py` only resolves ADB through an
explicit setting/PATH and binds that default for UIListener. The manual entry
files derive their source from `__file__`, use operator/current Python, generic
private config/state locations and inherited proxy settings. Their runtime hash
pin is synchronized. Tests inject and assert synthetic paths before module/default
binding; a synthetic child verifies the operator proxy remains inherited.

Shared protocol text is moved unchanged to `docs/protocol-v1.md`; component-local
protocol files link there. Reader-oriented docs/root scripts and an inert manual
config example are added. Legacy assets/modules/notices remain present. Old Git
history and ignored private/run/research/generated material are not imported.

The checks do not cover the paused [known issues](known-issues.md), new device
behavior, fresh-OS installation, model semantics, complete merchant/order activation
or study results. The Android build below verifies the integrated source with
existing toolchain caches; it does not establish any of those live outcomes. The original
component worktrees, paused fixes and historical evidence were not edited.

## Running the complete offline checks

Prepare the five offline Python dependencies, then supply existing JDK16,
org.json:20180813 and Android34 android.jar paths from the repository root:

```sh
export FOCALFLOW_PYTHON=/absolute/path/to/python3.8
export FF_JAVA_HOME=/absolute/path/to/jdk16
export FF_JSON_JAR=/absolute/path/to/json-20180813.jar
export FF_ANDROID_JAR=/absolute/path/to/android-34/android.jar
./scripts/check-offline.sh
```

These commands do not provision SDK/JAR caches. The Java checks use platform
stubs and extracted Service callbacks, not a native device/Looper. The measured
145-test run used an existing environment; a minimal new environment may skip
the two optional sounddevice-source checks.
